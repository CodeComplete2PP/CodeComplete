## 16장: 반복문 제어

### 16.1 반복문 종류 선택

- 반복 여부를 시작에서 판단하면 `while`, 끝에서 판단하면 `do-while` 형태가 적합함
- 일정 범위나 컬렉션을 순회하면 `for`를 사용해 초기화, 종료 조건, 증가를 한곳에 모음
- 반복 횟수가 정해지지 않았거나 종료 조건이 복잡하면 `while`이 의도를 더 잘 드러냄
- 언어가 제공하는 가장 단순하고 익숙한 반복 구조를 선택함
- 반복문 종류를 억지로 맞추기 위해 제어 변수를 비정상적으로 조작하지 않음

### 16.2 반복문 제어

#### 반복문 진입

- 반복문 바로 앞에서 제어 변수를 초기화함
- 반복문에 사용하는 초기화 코드를 다른 목적의 코드와 섞지 않음
- 무한 반복은 의도임이 분명한 문법으로 표현하고 종료 지점을 쉽게 찾게 함

#### 반복문 본문

- 본문을 짧게 유지하고 한 가지 작업만 수행하게 함
- 루프 제어에 영향을 주는 코드는 한곳에 모으고, 본문 중간에서 제어 변수를 몰래 바꾸지 않음
- `continue`는 남은 본문을 건너뛰는 의도가 명확할 때만 제한적으로 사용함
- 반복마다 변하지 않는 계산은 반복문 밖으로 옮김

#### 반복문 종료

- 종료 조건은 명백하고 결국 참이 되는 조건이어야 함
- 종료 조건을 반복문 시작이나 끝 한곳에서 확인하는 형태를 우선함
- `break`를 쓰면 반복문을 끝내는 이유가 바로 보이게 하고 여러 종료 지점을 만들지 않음
- 종료 뒤 제어 변수의 최종값에 의존하는 코드는 경계값을 명시적으로 검토함
- off-by-one 오류를 막기 위해 첫 값, 마지막 값, 빈 범위, 한 요소 범위를 확인함

#### 반복 변수

- 반복 변수는 반복문 안에서만 사용하고 범위를 최소화함
- 의미 없는 `i`, `j`, `k`는 짧고 단순한 인덱스 반복에서만 사용함
- 중첩 반복문에서는 각 변수의 역할이 구분되는 이름을 사용함
- 반복 변수를 부동소수점으로 증가시키며 정확한 종료값과 비교하지 않음

### 16.3 안쪽에서 바깥쪽으로 반복문 만들기

- 먼저 한 번의 반복에서 수행할 정상 작업을 작성함
- 그 작업을 반복 구조로 감싼 뒤 초기화와 종료 조건을 추가함
- 가장 일반적인 경우를 먼저 동작하게 하고 빈 입력과 마지막 반복 같은 경계를 보완함
- 복잡한 반복문을 한 번에 작성하기보다 단순한 본문에서 시작해 단계적으로 확장함

### 16.4 반복문과 배열의 대응

- 배열의 첫 인덱스와 마지막 인덱스를 반복 범위와 정확히 대응시킴
- 배열 길이를 직접 사용하고 별도의 매직 넘버로 범위를 반복하지 않음
- 여러 배열을 함께 순회하면 길이와 인덱스가 같은 의미를 갖는지 확인함
- 가능한 경우 인덱스보다 컬렉션 요소 자체를 순회해 경계 오류를 줄임

### 참고 자료

- 반복문의 정확성은 경계값 분석과 단위 테스트를 통해 확인할 수 있음

### 요점 정리

- 반복문 종류는 종료 조건의 위치와 반복 대상의 성격을 기준으로 선택한다.
- 반복문은 진입, 본문, 종료를 각각 단순하게 만들고 제어 코드를 한곳에 모아야 한다.
- 반복문은 안쪽의 한 번짜리 작업부터 만든 뒤 바깥쪽 제어를 추가하면 더 쉽게 작성할 수 있다.
- 배열과 반복 범위의 경계를 정확히 대응시키는 것이 off-by-one 오류를 막는 핵심이다.
