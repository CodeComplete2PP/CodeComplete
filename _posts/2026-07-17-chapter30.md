## 30장: 프로그래밍 도구

### 핵심 내용

- 설계 도구, 소스 코드 도구, 실행 코드 도구를 작업 단계에 맞게 사용함
- 편집기·IDE의 검색, 리팩터링, 탐색, 자동 완성 기능은 생산성을 높임
- 컴파일러 경고, 정적 분석, 디버거, 프로파일러, 테스트 도구를 조합함
- 도구가 제공하는 결과를 이해하지 못하면 자동화가 오히려 오류를 숨길 수 있음
- 직접 도구를 만들 때는 반복 비용과 유지보수 비용을 함께 계산함
- 도구에 대한 환상보다 실제 병목과 팀의 사용 능력을 기준으로 선택함

### 요점 정리

- 도구는 개발자의 판단을 대신하지 않고 반복 작업과 관찰을 돕는다.
- 좋은 도구 선택은 기능 목록보다 프로젝트의 실제 문제와 사용 방식에 달려 있다.
