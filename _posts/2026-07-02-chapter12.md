## 12장: 기본 데이터형

### 12.1 숫자 일반

- 숫자 타입은 범위, 정밀도, 표현 방식, 연산 규칙을 함께 고려해 선택함
- 타입 변환은 명시적으로 하고, 자동 변환에 의존하지 않음

### 12.2 정수

- 정수의 범위와 오버플로를 확인함
- 나눗셈의 반올림 규칙, 부호, 비트 연산의 의미를 언어별로 확인함

### 12.3 부동소수점

- 부동소수점은 대부분의 실수를 정확히 표현하지 못함
- 동등 비교 대신 허용 오차를 사용하고, 금액에는 적절한 정수·십진 타입을 사용함
- 계산 순서와 누적 오차가 결과에 영향을 줌

### 12.4 문자와 문자열

- 문자 인코딩과 문자열 길이의 기준을 명확히 함
- 문자열 결합·검색·복사는 성능과 경계 조건을 함께 점검함
- 버퍼 크기, 종료 문자, 다국어 문자를 고려함

### 12.5 불리언 변수

- 불리언은 참·거짓 상태를 표현할 때 사용함
- 복잡한 조건은 이름 있는 불리언이나 함수로 의미를 드러냄

### 12.6 열거형

- 열거형은 유효한 선택지를 제한하고 의미를 이름으로 표현함
- 숫자값을 직접 비교하거나 순서에 의존하지 않음

### 12.7 명명된 상수

- 매직 넘버를 이름 있는 상수로 바꾸어 의미와 변경 지점을 명확히 함
- 상수의 단위와 적용 범위를 함께 드러냄

### 12.8 배열

- 배열의 인덱스 범위와 경계를 명확히 하고 반복문과 일치시킴
- 배열이 실제로 표현하는 개념이 있다면 더 높은 수준의 추상화로 감쌈

### 12.9 자신만의 타입 만들기

- 타입 별칭과 사용자 정의 타입으로 도메인 의미를 표현함
- 서로 섞이면 안 되는 값을 타입으로 구분하면 오류를 컴파일 단계에서 줄일 수 있음

### 참고 자료

- 이 장에는 별도 참고 자료 목록이 없음

### 요점 정리

- 기본 데이터형은 단순한 저장 공간이 아니라 값의 의미와 허용 범위를 표현한다.
- 숫자 정밀도, 문자열 경계, 배열 인덱스, 자동 변환은 자주 오류를 만드는 지점이다.
